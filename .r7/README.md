# R7 repository context: Facebook-Challenge

This is a 2017 React practice project called **MyBook**, a Facebook-style page mockup. The app is under `practice1/`. `practice1/src/App.js` renders the heading, navigation, search field, status input, comments area, and friends/profile panel. `practice1/src/components/Comment.js` renders a sample comment with reply, like, dislike, and delete controls. Styles are in `App.css`, `friends.css`, and `index.css`.

The controls are present visually but the inspected components do not attach handlers or persist posts/comments. `practice1/README.md` is the stock Create React App guide, so it does not document custom behavior.

See [decisions.md](decisions.md) for the code-backed structure and [changes/2017-09.md](changes/2017-09.md) for the sole default-branch commit, `ab06e27de2e2a6348bdd2cc1afe60332be10eba5`.
